# flyers (전단지 이미지)

허브 앱의 '내 전단지' 코너에서 불러 쓰는 **전단지 원본 이미지** 폴더입니다.
(이름·전화번호는 앱에서 자동으로 얹히므로, 여기에는 연락처가 없는 원본만 둡니다.)

## 파일 이름 규칙
`연도-월_내용.jpg`  예) `2026-11_vip-50off.jpg`

## 현재 파일
| 파일 | 내용 |
|---|---|
| 2026-11_vip-50off.jpg | 11월 한정 VIP 고객 대상 평생 50% 할인 |
| 2026-11_secret-coupon.jpg | 만기고객 전용 시크릿쿠폰 |

## 주의
- 새 전단지를 올리거나 지난 전단지를 뺄 때는 앱의 전단지 목록도 함께 바꿔야 합니다.
- 파일 이름을 바꾸면 앱에서 이미지가 안 보입니다.
